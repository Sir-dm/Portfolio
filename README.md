# Sir_dm Portfolio

A beginner-friendly portfolio site for documenting a learning journey in web development and cybersecurity.

## Preview locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript; there is no build step or package installation.

## Publish with GitHub Pages

1. Create a public GitHub repository for this project, for example `portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub Pages will show the published site URL in the Pages settings after deployment.

## Personalize it

- Update the page title, intro, and learning topics in `index.html` as your interests develop.
- Add project cards when you have projects to share.
- Replace the GitHub profile link if your username changes.
- Add contact links only if you want them public.

This site describes learning goals and does not claim professional experience. Security work should stay within systems you own or have explicit permission to test.
